# 智账界面预览

这组文件用于正式开发前的视觉评审，不是产品业务代码。

## 输出

- `../00-overview.png`：四屏总览，1600×1000
- `../01-home.png`：首页，780×1688
- `../02-entry.png`：语音与文字记一笔，780×1688
- `../03-analysis.png`：分析月报，780×1688
- `../04-login-join.png`：登录与加入家庭，780×1688

## 视觉规范

- 应用图标使用项目根目录的 `图标.png`，预览时复制到 `assets/app-icon.png`。
- 主色为奶油白、灰猫深灰、鼠尾草绿和暖金，延续图标的星星与硬币元素。
- 390×844 手机视口，2 倍分辨率导出。
- 金额默认使用人民币，外币按当天汇率折算为人民币。
- 记一笔页面包含语音转文字和隐私消费入口。
- 所有页面内容均为静态示例，不包含真实交互、后端接口或业务逻辑。

## 重新生成

在项目根目录运行：

```powershell
.\previews\source\capture.ps1
```

脚本会自动同步最新图标、使用本机 Playwright Core 驱动浏览器截图，并校验五张图片的尺寸。
